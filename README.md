Connectly is a full-featured, real-time social networking web platform built on the ASP.NET Core ecosystem. The application is engineered following enterprise Clean Architecture (4-Layer structure) and the Repository Pattern to maintain strict separation of concerns, testability, and maintainability.  Core Concept & User ExperienceConnectly allows users to build an interactive social profile, connect with friends, share content, and communicate in real time:  Profiles & Personal Space: Users can register, log in, manage personal details (bio, profile avatar, and date of birth), and view dedicated profile pages containing personal timelines, media, and connection lists.  Dynamic Feed & Social Interactions: A chronological activity feed where users can publish posts, like, and leave comments. Visibility can be toggled using a Post Privacy Selector (Public, Friends Only, or Only Me), which is evaluated at the database query level for performance.  Instant Feed & User Discovery: A debounced instant search system enables users to discover posts and find other members across the platform.  Real-Time 1-on-1 Chat Portal: Direct messaging powered by SignalR with automated message routing. Messages between accepted friends land directly in the primary inbox, while messages from non-friends are automatically routed to a Message Requests folder. The chat includes live "Typing..." indicators and persistent read receipts.  Real-Time Notification Hub: Delivers instant toast alerts and in-app logs for friend requests, user tags, post interactions, and birthday reminders.  Birthday Reminder Background Worker: A background worker service (IHostedService) scans the database daily to alert users when their friends are celebrating a birthday.  Architectural Layers & Dependency RuleThe project strictly follows the Dependency Inversion Principle (DIP) where inward layers are independent of outer layers:  1. Connectly.Domain: Core enterprise entities (AppUser, Post, Comment, PostLike, Friendship, Message, Notification), domain enums, and business exceptions with zero external dependencies.  2. Connectly.Application: Business use cases, DTOs, validation rules, and repository interfaces (IUnitOfWork, IPostRepository); references only Domain.  3. Connectly.Infrastructure: Data persistence via Entity Framework Core ApplicationDbContext, SQL Server configurations, repository implementations, JWT generation, and background hosted workers; references Application and Domain.  4. Connectly.API: Presentation layer hosting REST controllers, SignalR WebSocket hubs, JWT authentication middleware, and Dependency Injection registration in Program.cs; references Application and Infrastructure.  Technical HighlightsBackend & Security: C# (.NET 8+), ASP.NET Core Web API, and ASP.NET Core Identity with stateless JWT bearer tokens (including custom query-token extraction for SignalR WebSockets).  Data Access: Entity Framework Core (Code-First migrations) with Microsoft SQL Server.  Real-Time Layer: SignalR Hubs (ChatHub and NotificationHub) for instantaneous bidirectional messaging and notification broadcasts.  Hosting Environment: Configured for deployment on Windows IIS / Monster ASP (SmarterASP.NET).
